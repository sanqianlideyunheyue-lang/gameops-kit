# 指标口径

本项目按 `game_id + player_id` 唯一识别玩家。日期使用 CSV 中的 `YYYY-MM-DD` 日历日；导入前请统一时区。

| 指标 | 口径 |
| --- | --- |
| 安装日期 | 玩家首次出现的事件日期；示例数据显式包含 `install` 事件 |
| 新增 | 安装日期落在筛选区间的去重玩家数 |
| DAU | 当日有 `session_start` 的去重玩家数 |
| 日均 DAU | 筛选区间内每日 DAU 的算术平均，包含 0 活跃日 |
| D1 / D7 留存 | 安装后第 1 / 7 个日历日有 `session_start` 的玩家数 ÷ 已到达观察日的新增玩家数 |
| 收入 | 筛选区间中 `revenue` 字段求和；导入数据需自行保持币种一致 |
| 漏斗 | 安装于筛选区间的玩家中，截至结束日期出现过前序全部事件的比例；适合一次性里程碑事件 |

筛选渠道、设备、版本时，使用玩家首次事件记录上的属性，避免同一玩家因后续版本变化被重复分组。日期筛选约束新增 cohort、趋势与收入；D1/D7 可读取该 cohort 在区间结束日之前的后续启动事件。区间末尾尚未到达 D1/D7 观察日的玩家不进入相应分母。

## 数据限制

- 模拟数据由固定随机种子生成，只用于展示流程。
- 导入 CSV 的首次事件未必等于真实安装。正式业务应使用可靠的安装表或身份表。
- 漏斗只验证事件是否出现，不验证精确发生顺序和转化时长。
- 活动标注与趋势同图仅用于观察；不能据此断言因果效果。
