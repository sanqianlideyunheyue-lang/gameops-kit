# 案例：定位关卡型小游戏的新手流程问题

此案例使用仓库内的合成数据，演示产品运营的分析与决策过程。结论不代表真实业务效果。

## 业务问题

新用户进入游戏后，应完成三个新手步骤。运营希望确认最近版本的新手转化是否有值得排查的变化。

## 操作路径

1. 打开「关卡型小游戏」，进入「问题定位」。
2. 保持全量数据，查看版本对比与四步漏斗。
3. 左侧设备选择 Android，再次对比版本 1.0 与 1.1。
4. 记录结论，并在「运营动作」中添加拟采取的版本修复或引导优化节点。

## 预期发现与运营判断

样例生成器将 Android 版本 1.1 的第三步通过概率调低，因此可观察到该群体教程末端的转化弱于 Android 版本 1.0。下一步应检查该步骤的界面、文案、性能与事件埋点，并结合版本发布时间、渠道构成和样本量核实。若要量化调整效果，应预先确定主要指标与观察窗口，尽可能采用对照组。

## 展示能力

这个案例展示了从总体指标下钻到特定人群、定义待验证假设、记录运营动作与写出下一步决策的过程。
